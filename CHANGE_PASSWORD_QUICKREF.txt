📍 LOCATION
   Settings Page → Security Section → Bottom of page
   URL: http://localhost:3000/settings.html

🔐 REQUIREMENTS
   ✓ Must be logged in
   ✓ Current password (for verification)
   ✓ New password (min 6 characters)
   ✓ Confirm password (must match new)

⚡ HOW TO USE
   1. Fill in current password
   2. Enter new password twice
   3. Click "Change Password" button
   4. Confirm the dialog
   5. Wait for success message
   6. Optionally logout and re-login

✅ VALIDATION CHECKS
   ✓ All fields filled
   ✓ New password min 6 chars
   ✓ New passwords match
   ✓ New ≠ current password
   ✓ Current password correct in DB

🎯 SUCCESS INDICATORS
   ✓ Toast: "✓ Password changed successfully!"
   ✓ Password fields cleared
   ✓ Optional logout prompt
   ✓ Can login with new password

❌ COMMON ERRORS
   "Please enter your current password"
      → Current field is empty
   
   "New password must be at least 6 characters"
      → Password too short
   
   "New passwords do not match"
      → Typo in new/confirm field
   
   "Current password is incorrect"
      → Wrong current password entered
   
   "Cannot connect to server"
      → Server offline or network issue

🔧 TECHNICAL DETAILS
   Frontend:  settings.html (lines 726-830)
   Backend:   api/auth.js (lines 121-175)
   Endpoint:  POST /api/auth?action=change-password
   Auth:      JWT Bearer token required
   Security:  bcrypt password hashing

💡 TIPS
   • Use strong passwords (mix of chars, numbers, symbols)
   • Password fields auto-clear on success
   • Can logout immediately for extra security
   • Fields auto-focus on validation errors
   • Confirmation required before changing

🔒 SECURITY
   ✓ JWT token verified
   ✓ Current password must match
   ✓ Passwords hashed with bcrypt
   ✓ Never stores plain text
   ✓ Parameterized SQL queries
