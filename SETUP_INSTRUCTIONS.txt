## TROUBLESHOOTING
##############################################

Problem: "Cannot connect to database"
Fix: Check POSTGRES_URL in .env.local is correct and includes ?sslmode=require

Problem: "Unauthorized" or login doesn't work  
Fix: Clear browser data (F12 > Application > Local Storage > Clear)

Problem: "Column password does not exist"
Fix: Run db\sql\repair_auth_schema.sql in Neon SQL Editor

Problem: Port 3000 already in use
Fix: Stop other processes or change port in package.json

Problem: PowerShell won't run scripts
Fix: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
